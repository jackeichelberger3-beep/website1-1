Updated index.html with a modernized look and a floating "Reset & Reload" button that clears local edits and reloads the site to use the PAGES_DATA built into the file.

How to use the new button
- Open the site in a browser and click the "Reset & Reload" button at the bottom-right.
- Confirm the prompt; this will clear the local storage keys used by the app and reload the page. After reloading the site will load pages from the PAGES_DATA in index.html (the file defaults) so any changes you commit to the repository will appear.
